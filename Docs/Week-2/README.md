# Week 2 - Project Setup & Documentation

## Overview

Week 2 focused on establishing an audit-ready project repository by implementing software engineering best practices for reproducibility, documentation, and version control. The repository was restructured to improve organisation, GitHub workflows were introduced through branching and pull requests, and Zotero was used to manage project references and generate automated citations for the research proposal.

---

## Learning Objectives

Week 2 focused on developing reproducible research workflows through:
- Creating a structured GitHub repository for the CariSurg project
- Implementing version control using Git branches, commits, pull requests and merges
- Managing references using Zotero
- Generating citations and bibliographies automatically
- Applying reproducible software engineering practices for healthcare AI projects

## Key Findings
Week 2 demonstrated the importance of reproducibility and project organisation in healthcare AI development. Establishing a structured repository, maintaining version control, and using automated reference management improved the maintainability and reproducibility of the project. These practices provide a strong foundation for the remaining stages of model development and ensure that future work can be efficiently reviewed, reproduced, and extended by collaborators.
