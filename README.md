# CariSurg MedTech Pathways Healthcare AI Programme Portfolio 
## Overview
Welcome to my CariSurg MedTech Pathways portfolio repository. This repository documents my progress throughout the Carisurg Healthcare AI Programme as I develop skills in Python programming, healthcare data analysis, clinical research and AI within a Caribbean context. 

## Who is this Repository for?
This repository is intended for CariSurg mentors, programme participants, clinical reviewers and anyone interested in the application of AI and data analysis within healthcare. 

## Repository Structure 

## Running the Project 
1. Clone the repository
2. Install the required Python libraries listed in requirements.txt
3. Open the notebooks using Jupyter Notebook or Google Colab

## Data Source
The analyses in this repository use a de-identified emergency department triage dataset provided as a part of the CariSurg MedTech Pathways Programme. The original dataset is not included in this repository 

## Healthcare AI Program Structure 

Week 0 focuses on onboarding into Clinical AI & Innovation workflow through:
- Data cleaning and exploratary data analysis
- Visualization of Mercer General Hospital emergency department triage data
- Interpretation of clinical vital signs
- Basic at-risk patient identification using rule-based logic

Week 1 focuses on emergency department triage research, the application of AI in clinical decision support, and the development of a research proposal for a 12-week AI-assisted triage pilot within a Caribbean healthcare setting.
